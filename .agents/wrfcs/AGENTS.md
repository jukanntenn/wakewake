# AGENTS.md — WRFCs

WRFCs are wakewake's RFCs: durable proposals and decision records — the why, the losing alternatives, the parts code and specs cannot carry. The full contract lives in [README.md](README.md); the documentation standard lives in [docs/AGENTS.md](../../docs/AGENTS.md).

**Every new WRFC triggers a duplicate check.** Grep `.agents/wrfcs/` for the topic first; update the record that already owns the decision instead of creating a twin.

**Never edit a WRFC into a different decision.** Supersede it: write a new record, cross-link both, and move this one only as its own verdict dictates.

**Every record is a bilingual pair.** The `.md` original and its `.zh.md` twin update together in the same change.
